# Albany-Athens Puzzle Circle

Website for the Albany-Athens Puzzle Circle, a free math program for kids in Athens County, Ohio, run by student volunteers.

- `index.html`: front page, with the handshake puzzle, the program, FAQ and the join form
- `puzzles.html`: three more puzzles (patterns, logic, counting)
- `site.css` and `site.js`: shared styles and scripts

There is no build step. Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings, Pages, deploy from the `main` branch, root folder).

The join form writes a note for the visitor to email. It does not send anything by itself.
