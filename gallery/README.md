Event photos for the gallery page.

Each photo has two files: a full size one (about 1600 px on the long side) and a small one ending in -sm.jpg (about 800 px) for the grid.
Strip location data before adding a photo.

To add one, open gallery.html and add a line to the list inside <script id="photo-list">, for example:
{ "file": "albany-6.jpg", "w": 1600, "h": 1200, "alt": "What is in the photo", "caption": "Short caption", "where": "Wells Library, Albany" }

w and h are the full-size photo's width and height in pixels. The page arranges tall and wide photos into even rows on its own.
Only post photos of kids with written permission from a parent or guardian, blur kids' faces, and never put a kid's name in a caption.
