Put event photos here (.jpg or .webp, about 1600 px on the long side).

Then open gallery.html and add one line per photo to the list inside <script id="photo-list">, for example:

[
  { "file": "wells-oct-2026-1.jpg", "alt": "Kids working on a puzzle at a library table", "caption": "Handshake puzzle at the Wells Library", "where": "Wells Library", "w": 1600, "h": 1200 }
]

Separate entries with commas. "where" adds filter buttons once there are photos from more than one place.
Only post photos of kids with written permission from a parent or guardian, and never put a kid's name in a caption.
